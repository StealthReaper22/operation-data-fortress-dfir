# Operation Data Fortress — DFIR Investigation

## Overview
Operation Data Fortress was a senior cybersecurity capstone project involving the investigation of a simulated enterprise security incident.

The investigation focused on reconstructing attacker activity using endpoint, network, cloud, and identity-related evidence.

## My Role
Forensic Lead — Team Tiger

My responsibilities included analyzing digital evidence, reconstructing attacker activity, maintaining forensic documentation, and contributing to incident findings and recommendations.

## Evidence Analyzed
- Windows endpoint artifacts
- Network traffic / PCAP evidence
- AWS CloudTrail logs
- Azure Activity Logs
- IAM records
- Authentication records
- Process information
- Registry activity

## Tools and Technologies
- Wireshark
- Windows forensic artifacts
- AWS CloudTrail
- Azure Activity Logs
- IAM analysis
- Digital forensic methodology
- Chain of custody documentation

## Investigation Process
1. Reviewed available evidence sources.
2. Correlated endpoint, network, cloud, and authentication activity.
3. Identified suspicious events and indicators.
4. Reconstructed key attacker actions.
5. Built a forensic timeline.
6. Documented findings and remediation recommendations.
